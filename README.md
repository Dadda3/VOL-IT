# Автоматизация UI-тестирования Practice Automation

Решение полуфинального задания олимпиады / кейс-чемпионата по направлению «Автоматизация тестирования (Java, Python)» (куратор: SimbirSoft).

Проект представляет собой комплексный фреймворк UI-автотестов на стеке **Java 17 + Selenium WebDriver + JUnit 5 + Maven + Allure Report**.

---

## 1. Стек технологий и архитектурные решения

* **Язык программирования**: Java 17 (LTS).


* **Библиотека взаимодействия с браузером**: Selenium WebDriver `4.25.0`.


* **Тестовый фреймворк**: JUnit 5 Jupiter `5.11.0`.


* **Инструмент сборки**: Apache Maven.

* **Отчетность и визуализация**: Allure Report `2.29.0`.


* **Архитектурный шаблон**: Page Object Model (POM).


---

## 2. Структура проекта

```text
├── pom.xml                                     
├── README.md                                    
└── src/
    ├── main/java/com/practiceautomation/pages/
    │   ├── BasePage.java                        # Базовый класс страниц: обертки кликов, скролла и ожиданий
    │   ├── CalendarPage.java                    # Page Object страницы /calendars/
    │   ├── ModalsPage.java                      # Page Object страницы /modals/ (Simple Modal и Form Modal)
    │   ├── AdsPage.java                         # Page Object страницы /ads/ (таймеры, оверлеи и темы)
    │   └── FormFieldsPage.java                  # Page Object страницы /form-fields/ (сбор списка Automation Tools)
    └── test/java/com/practiceautomation/
        ├── extensions/
        │   └── AllureScreenshotExtension.java
        └── tests/
            ├── BaseTest.java                    # Управление жизненным циклом браузера (Chrome / Firefox)
            ├── CalendarTest.java                # 8 позитивных и 4 негативных теста календаря (13 сценариев с учетом параметризации)
            ├── ModalsTest.java                  # 9 позитивных и 4 негативных теста модальных окон
            ├── AdsTest.java                     # 8 позитивных и 4 негативных теста рекламных окон
            └── FormFieldsTest.java              # Тест отправки формы со списком Automation Tools

```

## 5. Инструкция по установке и запуску тестов

### Требования к окружению

* **JDK**: версия 17 или выше.


* **Maven**: версия 3.8+.


* **Браузеры**: Google Chrome или Mozilla Firefox.



### Команды выполнения

1. **Компиляция проекта**:
```bash
mvn test-compile

```


2. **Запуск всех автотестов в браузере Google Chrome**:


```bash
mvn clean test

```


3. **Запуск всех автотестов в браузере Mozilla Firefox**:
```bash
mvn clean test -Dbrowser=firefox

```


4. **Запуск отдельного тестового класса**:
```bash
mvn test -Dtest=ModalsTest

```

## 6. Формирование и просмотр отчетов Allure

В проекте настроен плагин `allure-maven` и AspectJ Weaver для детального отслеживания шагов тестов (`@Step`):

```bash
# Генерация статического HTML-отчета
mvn allure:report

# Локальный запуск встроенного веб-сервера и автоматическое открытие отчета в браузере
mvn allure:serve

```
